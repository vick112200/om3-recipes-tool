# 截图放这里

README 里引用的是下面三个名字（宽度 250 px 显示，手机截图 1080×2400 或 412×900 都行）：

| 文件名 | 拍什么 |
|---|---|
| `1-home.png` | 配方合集首页（搜索栏 + 筛选 + 一张配方卡的色轮） |
| `2-recipe.png` | 一条配方的详情（色轮 + 参数 + 样片） |
| `3-connect.png` | 连接相机页（连接相机 / 扫码连接 两个按钮那屏） |

放好之后，把根目录 `README.md` 里那段截图注释的 `<!--` 和 `-->` 删掉即可。

（拍图小技巧：手机截图直接拖进来就行；要更清晰可以用 `scripts/_shots.py`，它用无头 Chrome 按 412×900、2 倍像素渲染。）
